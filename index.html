Managed Switching & Backend Architecture

• Serialized Execution: Local backends bind to 127.0.0.1 (ports 8080/8081 for llama.cpp, port 8090 for Strata HIP). The GPU lock is held exclusively per request/stream; systemd cgroups enforce mutual exclusion (Conflicts=).

• Idle Persistence: Once loaded, a model remains resident indefinitely (idle_unload_s: 0) to eliminate cold startup latency on subsequent prompts. Unloading occurs strictly on explicit model switches, controlled service stops, or failures.

• Streaming Support: Public Cloudflare Quick Tunnels do not support SSE streaming; web chat requests execute with stream: false (bounded to 512 tokens). Full native SSE streaming is supported directly on LAN (192.168.0.12:8000) and Tailscale (100.64.91.97:8000) routes.

• Context Scaling & PCIe 4.0 Upgrade: Qwen3.8-Flash-Next natively supports 256K (262,144) context. It is currently deployed at 128K (131,072) to maximize decode speed (56.1 tok/s) and preserve VRAM expert cache slots on the current PCIe 3.0 host. A prepared 256K configuration is verified and documented in /mnt/fast_models/strata/UPGRADE-PCIE4-256K.md for cutover when upgrading to PCIe 4.0.

• Opus 5.5: antigravity-claude-opus-5-5-high maps to exact upstream claude-opus-5-5-high; the retired 4.6 route has no alias. The existing top_p drop rule is retained. The bridge runs its locked local package directly with Bun; patchedDependencies preserves the native tier ID and configured port across reinstalls, without waiting for a quota-cache refresh.
